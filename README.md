## 🚀 Getting Started

### Prerequisites

Install a Java Development Kit (JDK) and verify the installation:

```bash
java -version
javac -version
```

### Clone the repository

```bash
git clone https://github.com/reemadsouza2006-dev/leetcode-java.git
cd leetcode-java
```

### Run a Java program locally

For a Java file containing a `main()` method:

```bash
javac FileName.java
java FileName
```

Replace `FileName` with the actual class and file name.

**Note:** LeetCode submissions commonly use `class Solution` without a `main()` method. Such files must be submitted through LeetCode or tested locally using an appropriate test setup.
